2Theory & Working (Firing Angle Control)

What is an AC Voltage Controller?

  • An AC voltage controller changes the RMS value of AC output voltage without changing its frequency.
  • It does this by controlling the firing angle α of the SCRs.
  • Used as a fan regulator, light dimmer, and heater control.

Working — Step by Step

  1. Positive Half Cycle (0 to π):
    The AC supply goes positive. T1 is forward-biased. At angle α, a gate pulse is given to T1. T1 fires and conducts from α to π, passing current through load R. After π, supply reverses → T1 turns OFF naturally (line commutation).
  2. Negative Half Cycle (π to 2π):
    The supply goes negative. T2 is forward-biased. At angle π + α, a gate pulse is given to T2. T2 fires and conducts from (π + α) to 2π, passing current in reverse through load R. After 2π, T2 turns OFF naturally.
  3. Load receives both half cycles — so it is a full-wave controller.
  4. By varying α from 0° to 180°, we control how long each SCR conducts per cycle, thus controlling the RMS output voltage.

Firing Angle (α) Control

α = 0° → SCR fires at the very start → Maximum output voltage (= full supply)
α = 90° → SCR fires at mid-cycle → Medium output voltage
α = 180° → SCR never gets time to conduct → Zero output voltage

RMS Output Voltage Formula

Vo(rms) = Vs × √[ (1/π) × (π − α + sin(2α)/2) ]

where: Vs = Peak supply voltage, α = Firing angle
🧠 Memory Tip: "More α = less voltage. Less α = more voltage. α = 0 → full power. α = 180 → zero power."

Key Features

  • Natural / Line Commutation — SCRs turn OFF automatically when supply current crosses zero. No forced commutation needed.
  • Full-wave operation — Both +ve and −ve halves are utilized → better waveform than half-wave.
  • Simple circuit — Only two SCRs and a gate firing circuit needed.
  • Smooth control — Output voltage varies smoothly from 0 to Vs by changing α.

(iii) Output Voltage — vo

Zero from 0 to α (SCR not yet fired), then follows the sine wave from α to π. Repeats for negative half. The chopped sine wave shows reduced RMS value.

(iv) Output Current — io

For a purely resistive load, current is always proportional to voltage (i = v/R). So the output current waveform has the exact same shape as the output voltage.

🧠 Memory Tip for Waveforms:
  • vs → Full uninterrupted sine wave (supply is always there)
  • Gate G1 → Short spike at α (every +ve half cycle)
  • Gate G2 → Short spike at π+α (every –ve half cycle)
  • vo → Zero from 0→α, then sine from α→π; zero from π→(π+α), then −sine from (π+α)→2π
  • io → Exactly same shape as vo (because load is pure R)

4Quick Summary for Exam Writing

  1. Two SCRs anti-parallel — T1 for +ve half, T2 for −ve half.
  2. Gate pulse at angle α triggers the SCR to start conducting.
  3. SCR conducts from α to π (or π+α to 2π) — rest of the time output is zero.
  4. Natural commutation — SCR turns OFF at supply zero crossing (no external circuit needed).
  5. Increasing α → less conduction time → lower RMS output → less power.
  6. For R-load — current waveform is identical to voltage waveform (i = v/R).
  7. Applications: Fan speed regulator, light dimmer, AC heater control, induction heating.
Exam formula to remember:
Vo(rms) = Vm/√2 × √[ 1 − (α/π) + sin(2α)/(2π) ]
